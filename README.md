# Linear-regression-property-valuation-in-Xindian-district

**Прогнозирование цены за единицу площади в районе Синьдянь (Тайвань) на основе публичных данных.**

## 🎯 Задача
Построить интерпретируемую модель регрессии для предсказания стоимости жилья.  
**Тип задачи:** Множественная линейная регрессия.  
**Метод решения:** Ручная реализация нормального уравнения (МНК) на NumPy без использования готовых библиотек ML.

## 📊 Данные
- **Источник:** UCI Machine Learning Repository (Real Estate Valuation Data Set)
- **Объем:** 414 записей о сделках 2012–2013 гг.
- **Признаки:** возраст дома, расстояние до метро, кол-во магазинов, дата, геокоординаты.

## 🔧 Этапы работы
1. **Очистка данных:** удалены выбросы (процентильный метод 1%) и аномалии (расстояние до метро > 6000 м).
2. **EDA:** визуализация связей признаков с целевой переменной (Plotly).
3. **Отбор признаков:** выбраны 3 ключевых фактора (возраст, расстояние до метро, число магазинов).
4. **Моделирование:** реализована модель с обучением на 80% данных.
5. **Оценка:** сравнены 3 конфигурации модели для обоснования выбора.

## 📈 Результаты

| Метрика | Значение |
|---------|----------|
| **R²**  | 0.60     |
| **MAE** | 6.2      |
| **RMSE**| 7.68     |

**Уравнение модели:**  
`Цена = 41.03 – 0.21·Возраст – 0.005·Расстояние_до_метро + 1.42·Кол-во_магазинов`
